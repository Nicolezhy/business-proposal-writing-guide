# 商业方案写作指南 - Skill使用说明

## 概述

这是一个基于9份实战商业方案提炼的写作系统,帮助用户快速撰写结构化、去AI味、可执行的商业运营方案。

**版本**: v1.2.0  
**作者**: Nicole  
**最后更新**: 2026-09-09

---

## 适用范围

### 支持的AI Agent
- ✅ Claude Code (Anthropic)
- ✅ Codex (OpenAI)
- ✅ Gemini (Google)
- ✅ ChatGPT with Custom Instructions
- ✅ 其他支持skill/system prompt的agent

### Agent最低要求
- **必需**: 能够理解和执行system prompt/skill instructions
- **推荐**: 具备在线搜索能力(WebSearch/Browsing)用于行业调研和竞品分析
- **可选**: 如果没有搜索能力,可以让用户提供行业资料

## 安装方法

### 方法1: Codex (推荐)
```bash
# 将整个文件夹复制到Codex的skills目录
cp -r 商业方案写作指南 ~/.codex/skills/
```

### 方法2: Claude Code
```bash
# Claude Code已经自动识别.codex/skills目录下的技能
# 确保skill.md在正确位置即可
```

### 方法3: Gemini / ChatGPT
1. 打开 `skill.md` 文件
2. 复制全部内容
3. 在Gemini/ChatGPT中:
   - Gemini: 设置 → Custom instructions → 粘贴
   - ChatGPT: Settings → Custom instructions → 粘贴

### 方法4: 其他Agent
将 `skill.md` 内容作为system prompt或initial instructions导入

## 使用方法

### 快速开始

直接对agent说:
```
帮我写一份[产品名]的新媒体运营方案
```

agent会自动:
1. 问你7个核心问题(判断产品阶段/交易类型/渠道/预算)
2. 进行行业调研(如果有搜索能力)
3. 拆解竞品(4个维度)
4. 生成章节大纲
5. 逐章引导你写作
6. 检查字数/重复/AI味

### 完整流程示例

```
用户: 帮我写一份OneGate Wallet的新媒体运营方案

Agent: 你好!我是商业方案写作顾问...
       问题1: 客户是谁?做什么的?
       
用户: NEO N3生态的Web3游戏钱包

Agent: 问题2: 产品/品牌现在是什么状态?
       1. 有没有稳定的获客渠道?
       2. 知道哪类人会买你的产品吗?
       ...

[7个问题问完后]

Agent: 📊 行业快速调研结果...
       开始写第一章...
```

## 核心功能

### 1. 产品生命周期诊断
通过4个问题判断产品处于:
- 引入期(验证阶段)
- 成长期(快速增长)
- 成熟期(稳定扩张)
- 衰退期(寻找第二曲线)

### 2. 渠道差异化策略
根据渠道组合设计差异化内容:
- 小红书(获客引流)
- 公众号(品牌沉淀)
- 社群(私域转化)
- 线下(体验转化)

### 3. 竞品4S拆解
从4个维度拆解竞品:
- 对标内容(怎么讲)
- 对标设计(怎么呈现)
- 对标视觉(品牌识别)
- 对标变现(商业模式)

### 4. 8大营销框架
按需引入营销理论:
- SWOT分析
- 4P营销组合
- 4C营销理论
- STP理论
- AARRR增长模型
- 消费者决策漏斗
- AIDA模型
- RFM用户分层

### 5. 去AI味检查
自动检查并删除:
- 45+禁止句式(不是...而是/既...又...)
- 行业黑话(赋能/链接/推动...)
- 夸大表达(颠覆性/革命性...)

## 输出标准

### 方案结构
**纯线上**(5-6章):
1. 核心洞察
2. 核心运营策略
3. 渠道内容策略
4. 执行排期
5. 目标与报价

**需线下**(6-7章):
1. 核心洞察
2. 核心运营策略
3. 产品线系统分析
4. 不同平台内容策略
5. 线下活动策划
6. 阶段目标
7. 服务报价

### 字数规范
- **总字数**: 4000-8000字
- **每章字数**: 不超过1500字
- **原则**: 去重复,去冗余,每段只说一件事

## 常见问题

### Q1: 我的agent没有搜索功能怎么办?
A: Skill会提示你提供行业资料或竞品信息。你可以:
- 自己搜索后复制给agent
- 提供竞品链接/截图
- 基于你已知的信息让agent分析

### Q2: 我想写简短一点的方案可以吗?
A: 可以。在开始时告诉agent:
```
我希望写简洁版,4000-5000字就够了
```

### Q3: 我想跳过某些章节可以吗?
A: 可以。在生成大纲后告诉agent:
```
第三章我不需要,直接跳到第四章
```

### Q4: 我可以使用自己的营销框架吗?
A: 可以。告诉agent:
```
不用SWOT,我想用PEST分析
```

### Q5: 生成的方案还是有AI味怎么办?
A: 把内容发给agent,说:
```
帮我检查一下AI味,把所有禁止句式都删掉
```

## 高级用法

### 技巧1: 分段式写作
如果方案很长,可以分章节写:
```
我们先写第一章,写完我再让你写第二章
```

### 技巧2: 多轮迭代
对某一章不满意,可以多次修改:
```
第一章太长了,帮我压缩到1000字以内
```

### 技巧3: 自定义模板
告诉agent你的特殊需求:
```
我们公司的方案必须包含"风险控制"章节
```

### 技巧4: 复用到其他项目
第二次使用时可以说:
```
参考上次OneGate的方案结构,给我写一份[新产品]的方案
```

## 限制与边界

### ✅ Skill擅长
- 产品生命周期诊断
- 渠道差异化策略
- 竞品拆解
- 逐章写作引导
- 去AI味检查

### ❌ Skill不擅长
- 从0到1的创意策划
- 实时数据获取(依赖搜索能力)
- 行业深度专业知识
- 具体内容生产(文案/设计)
- 具体预算金额决策
