# 商业方案写作指南

基于6年实战营销专家提炼的写作方案引导指南,适用于品牌营销、品牌增长、营销策略、品牌定位、用户增长、品牌战略、出海营销等方案的撰写。

通过"七步工作流 + 八大营销框架",并强制去除AI味儿黑名单,帮助你快速产出专业的商业化方案。

## 核心能力

- ✅ 产品生命周期诊断(引入期/成长期/成熟期/衰退期)
- ✅ 渠道差异化策略(小红书/公众号/社群/线下)
- ✅ 竞品4S拆解(内容/设计/视觉/变现)
- ✅ 8大营销框架按需引入(SWOT/4P/4C/AARRR/STP/AIDA/RFM/消费者决策漏斗)
- ✅ 45+AI味黑名单检查
- ✅ 引导性提问系统(6个关键节点主动确认)

## 输出标准

- **字数控制**: 4000-8000字
- **结构清晰**: 5-7章完整方案(核心洞察/运营策略/渠道内容/执行排期/目标报价)
- **去重复**: 每段只说一件事,同样观点不在不同章节重复
- **无AI味**: 删除所有"不是...而是"/"既...又"等禁止句式

## 快速开始

### 支持的AI Agent

- Claude Code (Anthropic)
- Codex (OpenAI)
- Gemini (Google)
- ChatGPT with Custom Instructions
- 其他支持skill/system prompt的agent

### 安装方法

#### 方法1: Codex / Claude Code

```bash
# 将整个文件夹复制到Codex的skills目录
cp -r 商业方案写作指南 ~/.codex/skills/
```

#### 方法2: Gemini / ChatGPT

1. 打开 `skill.md` 文件
2. 复制全部内容
3. 在Gemini/ChatGPT中:
   - Gemini: 设置 → Custom instructions → 粘贴
   - ChatGPT: Settings → Custom instructions → 粘贴

### 使用示例

```
用户: 帮我写一份[产品名]的新媒体运营方案

Agent: 你好!我是商业方案写作顾问...
       问题1: 客户是谁?做什么的?
       
用户: [回答7个核心问题]

Agent: 📊 行业快速调研结果...
       开始写第一章...
```

## 功能特色

### 1. 产品生命周期诊断

通过4个问题判断产品处于:
- 引入期(验证阶段)
- 成长期(快速增长)
- 成熟期(稳定扩张)
- 衰退期(寻找第二曲线)

### 2. 竞品4S拆解

从4个维度拆解竞品:
- 对标内容(怎么讲)
- 对标设计(怎么呈现)
- 对标视觉(品牌识别)
- 对标变现(商业模式)

### 3. 8大营销框架

按需引入营销理论:
- SWOT分析
- 4P营销组合
- 4C营销理论
- STP理论
- AARRR增长模型
- 消费者决策漏斗
- AIDA模型
- RFM用户分层

### 4. 去AI味检查

自动检查并删除:
- 45+禁止句式(不是...而是/既...又...)
- 行业黑话(赋能/链接/推动...)
- 夸大表达(颠覆性/革命性...)

## 常见问题

**Q: 我的agent没有搜索功能怎么办?**  
A: Skill会提示你提供行业资料或竞品信息。你可以自己搜索后复制给agent。

**Q: 我想写简短一点的方案可以吗?**  
A: 可以。在开始时告诉agent: "我希望写简洁版,4000-5000字就够了"

**Q: 生成的方案还是有AI味怎么办?**  
A: 把内容发给agent,说: "帮我检查一下AI味,把所有禁止句式都删掉"
